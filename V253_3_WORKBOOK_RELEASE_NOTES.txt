StepCat Calculator v253.1 + Workbook v253.3
Release date: August 31, 2026

Workbook v253.3 is a clarity, compact-label, documentation, and report-presentation update. Core calculator math and the v253.2 workbook profitability formulas/reporting structure remain unchanged.

Current user-facing terminology
- Payment / Record Type uses "Membership Fee" instead of "Subscription / Membership Fee".
- Current help, workbook instructions, Summary, Record Review, and Game Comparisons use Membership Fee wording.
- Backward-compatible workbook detection continues to recognize older Subscription-style records where necessary.

Workbook refinements
- Record Review excludes Membership Fee rows from the game index and uses matching blue, amber, and red status bands for In Progress, Ready to Finalize, and Estimate Date Issues.
- Game Comparisons uses current Membership Fee wording and tighter spacing between Paid Game Performance and Free Game Chip Performance.
- Carryover instructions use Prior Membership Fees and preserve the existing A:M / N:Z safety rules.
- Best Results and current report screenshots are aligned with Workbook v253.3.

Guide and site refinements
- Quick Start information boxes focus on user actions rather than developer-facing rationale.
- Guide illustrations can be tapped or clicked to enlarge for easier reading.
- Current v253.3 screenshots replace outdated guide illustrations where the interface/workbook changed.
- Documentation-only scrollbars and unnecessary spreadsheet headers are removed from guide copies where they add no instructional value.
- The current public workbook button points to Workbook v253.3.

Migration
Earlier corrected workbooks can continue to calculate normally. Updating is recommended if a workbook predates the August 11 corrections, shows formula/reference problems, or if the current v253.3 presentation and documentation are desired. Transfer only A:M through the last actual record row; do not copy N:Z, headers, whole sheets, reports, or charts.
