1. Purpose

StepCat calculates projected payouts and records completed results. It stores Saved History locally and copies one exact A–M workbook row. The matching workbook calculates N–Z, reviews data quality, and builds reports.

v252.1 R9 retains the v252 protections for destructive actions, permanent SC Record IDs, Free Game validation, safe unfinished-entry recovery, and startup-only drawer preferences. It keeps the dynamic Required/Optional labels and compact information dialogs from the prior correction pass, while giving Optional Fields different closed/open helper text, centering the main Write Feedback title and helper, and adding short descriptions beneath every Quick Explanation title.

v252.1 is the corrected follow-up to v252. Publish it only after the short hosted-device checklist passes.

2. Recommended workflow

Progressive border cue: gold identifies the single step or field to work on now, the selected choice uses the stronger gold treatment, green identifies a completed step, and locked steps remain neutral.

  1. Choose Entry Mode.
  2. Confirm Membership Type.
  3. Enter required calculation fields.
  4. Use Show Optional Fields only when the optional record fields are needed.
  5. Calculate & Save.
  6. Copy the row to the workbook, or finalize an Estimate in place when the game ends.

3. Entry Modes

Estimate

Estimate projects a likely payout from Gross Pot and Eligible Players. Non-Member estimates use the Adjusted Pot after the 15% deduction. Estimate cards show Estimated Earned, Accounting Result = N/A until finalized, and ROI = N/A.

Finalized

Finalized records a completed result. Final Earned determines Profit, Draw, or Disqualified accounting. Switching modes keeps the current unfinished entry; Start New Entry begins a different challenge.

4. Membership Type

Member uses the full Gross Pot. Non-Member uses 85% after the 15% deduction. Membership can optionally be remembered, but validation still requires a confirmed selection when nothing is remembered.

5. Entry fields and contextual help

ColumnsPurpose
A–FGame identity, dates, Entry Mode, Membership Type, and Payment / Record Type.
G–JGross Pot, Entry Fee, Eligible Players, and Total Players.
K–MFinal Earned / Chips, Disqualified / Lost Entry Fee, and Notes.

Game Entry contains the calculation fields. Optional Fields opens optional record information such as Game Name, dates, Date Format, and Payment / Record Type. Field labels keep the information button separate from the requirement label. Before Entry Mode is chosen, mode-dependent fields say Select Entry Mode. In Estimate, Gross Pot and Eligible Players say Required. In Finalized, those fields say Optional while Final Earned / Chips says Required unless Disqualified is selected. Date Format is a web setting and has no requirement badge. Required must be completed; Optional may be left blank and can still be entered for record or comparison details. During Game Entry, the first required field needing attention receives the gold current-action border; the cue advances as fields are completed.

6. Validation

Blocking errors use three coordinated layers: an exact inline message beside the affected field, a flat informational summary beneath Calculate & Save, and one short toast after the user attempts to save. StepCat scrolls to the first invalid field.

  • Required fields must be present.
  • Eligible and Total Players must be whole numbers.
  • Eligible Players cannot exceed Total Players.
  • End Date cannot precede Start Date.
  • Finalized results require Final Earned unless Disqualified is selected.

Success toasts are brief; warnings and actionable errors remain slightly longer, while persistent inline messages stay until corrected.

Free Game rule: Free Game records must use a $0 Entry Fee in both Estimate and Finalized modes. StepCat blocks a non-zero fee before saving.

8. Saved History

Saved History persists locally and supports copy-one, copy-all, Clear History, and Restore History. Copy All Sheet Rows remains the primary action; the copy guidance appears next, followed by Restore History and Clear History as maintenance controls. Individual deletion now provides a brief Undo action. Every record has a stable non-editable SC-#### Record ID. Named records show it as secondary text; unnamed records use it in the fallback title and workbook Game Name.

Each Estimate card includes a visible Finalize This Estimate action. This is the correct image for the Saved History section; it replaces the unrelated screenshot previously noted in Section 7 of the older guide.

9. Finalize an Estimate without duplication

Finalize This Estimate updates the existing Saved History item, preserves its SC Record ID and chronological position, and scrolls to the record actually updated. Legacy Free Game Estimates with a non-zero fee are blocked until corrected.

In the workbook, paste the finalized A–M row over the same game’s existing A–M cells. Do not add a second row for the same game.

10. Copying to the workbook

Copy This Sheet Row copies one tab-separated A–M row. Copy All Sheet Rows copies every saved row without headers. Optional fields remain blank; intentionally non-applicable values use N/A where the workbook expects that distinction.

When Game Name is blank, the copied Game Name uses Unnamed Game - SC-#### or Unnamed Estimate - SC-#### rather than an empty cell.

11. Profitability Analysis workbook

Instructions and color coding

Every instructional row is assigned a consistent visual category. Rows 17–18 have sufficient height and wrapping. The calculations section now flows directly from Profit to Draw with no hidden spacer row. Major sections are separated by deliberate white space, the What’s New area uses one orange header, Google Sheets workflow uses a blue section header, and compatibility and release-safety notes use green.

Game Records

A–M are pale-gold user inputs. N–Z are blue-gray formulas. Result cells use green, gray, blue, yellow, or red according to meaning. Row 4 is taller so wrapped headers are not clipped.

Record Review

Record Review specifically flags Free Game rows with a non-zero Entry Fee. Valid Free Game rows with a $0 fee receive no contradiction warning.

12. Reports and fees

Games by Result uses exact counts for Profit, Draw, and Disqualified completed paid games. Subscription/Membership Fee rows are excluded and tracked separately. Actual Running Net Profit subtracts those non-game costs from Net Game Profit.

13. Settings

All ordinary setting changes save automatically. Default-open choices apply only when StepCat loads or refreshes; they do not reset live drawer states while the user works. Restore Defaults is a confirmed bulk action and returns Haptic Feedback to Low.

  • Visible sections and exact main-page names.
  • Default Open Sections.
  • Remember Entry Mode, Membership Type, and Payment / Record Type.
  • Remember unfinished Game Entry inputs.
  • Show Spreadsheet Copy Help.
  • Remember guide progress.

Disqualified is never remembered for a new entry.

Remember unfinished Game Entry inputs stores only unfinished work. Successful saves clear the completed draft, and Disqualified never returns through draft recovery.

14. Help and documents

Each Quick Explanation header includes a short helper line describing the information inside. Help & Resources uses collapsible sections and exact destination labels. Remember Guide Progress is one shared setting in Settings and the Quick Start Guide.

15. Installation and shortcuts

The state-aware Install StepCat card shows Install StepCat when a browser prompt is available, Installation unavailable in a local or unsupported context, and is hidden when the app is already installed. Detailed platform methods are behind the information button. It opens a compact dialog with X and Close controls instead of navigating into Help & Resources.

16. Feedback

The main Write Feedback action uses the same orange gradient and light text as Show Math, with its title and helper text centered at every responsive width. It opens a dialog, copies the message, and attempts to prepare an email. Browser or device restrictions may affect whether the email app opens.

17. Migration and release safety

Users can keep the previous hosted release available while v252.1 is tested before production replacement. Existing v252 Google Sheets copies remain compatible. The included v252.1 workbook is a visual-clarity update, so replacing a working spreadsheet is optional. Existing Saved History records receive SC Record IDs in their original order when the upgraded app first loads; existing workbook rows do not need IDs.

  1. Keep the older workbook as a backup.
  2. Compare A–M headers.
  3. Copy populated A–M values only.
  4. Do not copy whole sheets or N–Z formulas.
  5. Verify Record Review, totals, and reports.

18. Troubleshooting

Calculate does not continue

Correct the highlighted inline fields. The status notice above Calculate & Save reports how many fields need attention.

Membership or Entry Mode reset

Enable the corresponding Remembered Entry Choice setting. If it remains off, a fresh confirmation is intentional.

Estimate is below the Entry Fee

The card still shows the exact projection. Estimated Break-Even Point gives the relevant eligible-player count; finalized accounting remains N/A.

Copied row did not calculate

Paste into the column-A cell, not cell-edit mode, and preserve N–Z. Record Review identifies missing formulas.

Installation unavailable

Open the hosted page in a supported browser or use the information button for Add to Home Screen methods.

Free Game fee is rejected

Free Game records require a $0 Entry Fee. Change the fee to 0 or use another Payment / Record Type.

A saved entry returned as an unfinished draft

v252.1 retains completed-draft cleanup after a successful save. Confirm that the current package and updated service worker are active.

A drawer changed after opening Settings

v252.1 preserves live drawer state. Default-open settings apply on the next load or refresh.
