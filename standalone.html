1. Purpose

StepCat is a mobile-first payout calculator and recordkeeping tool. It can project a payout before a game is complete, save the official amount returned afterward, retain recent local history, and copy clean rows into the matching workbook.

StepCat is an independent project. Estimates may differ from an official posted result. Use Finalized mode and Final Earned Amount for completed records.

2. Entry Modes

Estimate

Requires Gross Pot, Entry Fee, and Eligible Players. Total Players adds elimination context but does not change the payout.

Finalized

Requires Entry Fee and Final Earned Amount unless Disqualified / Lost Entry Fee is selected. Gross Pot and player counts are optional reference data.

Compact inline status strips confirm the selected Entry Mode and Membership Type. Tapping Member or Non-Member confirms that side in both Estimate and Finalized modes; no separate confirmation button or temporary selector toast is used. Membership confirmation resets when the record identity, Entry Mode, or Membership Type changes, or when Clear Fields is used.

4. Entry Fields

Game & Record Information

  • Game Name: identifies Saved History and workbook records.
  • Start and End Dates: copied using the selected Date Format. An End Date before the Start Date is flagged immediately and pauses calculation.
  • Payment / Record Type: free text. Common entries include Cash, Points, Hybrid, and Free Game. Free, Free Game, and Free Entry are normalized and copied as Free Game.
  • Notes: optional text copied into workbook column M. Hybrid cash/points breakdowns belong here.

Calculation Information

  • Entry Fee: amount paid; enter 0 for a free or covered entry.
  • Gross Pot: full pot before a Non-Member deduction.
  • Eligible Players: players still eligible for payout.
  • Total Players: optional context used with Eligible Players to calculate Eliminated Players and Elimination Rate, including for Free Games.
  • Final Earned Amount: total returned, not merely the extra profit. For a Free Game, enter the number of chips/game-credit units awarded.

The currently active field uses a light focus state. When calculation cannot continue, StepCat opens the relevant section, scrolls to the first missing or invalid control, and temporarily turns the target field light with a gold outline. Editable fields are highlighted without receiving the cursor or opening the keyboard automatically; toggle controls are outlined without forcing the keyboard open.

5. Result Rules

v246.1 cent alignment: StepCat rounds the payout-minus-Entry-Fee difference to two decimal places before assigning Profit or Draw. A difference that displays as $0.00 is a Draw. This matches the workbook formula rule.
Profit

Return above Entry Fee. Profit = Return − Entry Fee. ROI = Profit ÷ Entry Fee × 100.

Draw

A normal return equal to or below Entry Fee. Draw amount equals the Entry Fee; Profit/Loss and ROI are 0.

Below-fee Estimate

The exact raw estimate remains visible. StepCat does not replace it with the Entry Fee, even though Draw accounting remains $0.00.

Disqualified

The prominent Finalized Status panel records a disqualification. For paid games, Final Earned becomes $0.00, the full Entry Fee is lost, and ROI is −100.0%. For Free Games, the status is preserved but the monetary loss remains $0.00.

StepCat does not treat a normal below-fee finalized return as a partial monetary loss. Only Disqualified / Lost Entry Fee records a paid-game loss.

6. Free Games

A record with a $0 Entry Fee, or a Payment / Record Type of Free, Free Game, or Free Entry, is classified and copied as a Free Game. Any amount returned is recorded as chips/game credit, not cash.

  • ROI displays N/A — No Entry Fee because there was no cash investment.
  • Free Game chips are excluded from Gross Profit Earned, Net Profit, Running Net Game Profit, Actual Running Net Profit, and Game Records column Z.
  • Summary reports Free Game Chips Earned separately, and Game Comparisons reports Free Game Chip Performance separately.
  • Free Games remain outside paid-game Profit/Draw/Loss counts and paid-game ROI comparisons.
  • When Eligible Players and Total Players are supplied, Free Games calculate Eliminated Players and Elimination Rate like other step challenges.
  • A disqualified Free Game records the status, earns 0.00 chips, and records no monetary loss.

7. Saved History

  • Every Calculate & Save action creates one Saved History card.
  • Each card shows the outcome, key amounts, and essential record details. Payment / Record Type and Entry Fee are separate when applicable. Gross Pot and any Non-Member deduction/Adjusted Pot lines appear directly in the same details area, without a separate calculation panel.
  • The complete A–M field list is not repeated on screen.
  • Copy This Sheet Row: copies the exact A–M workbook row represented by that card.
  • Delete: permanently removes one Saved History record after confirmation.
  • Clear History: clears all history but keeps one restore backup.
  • Restore: restores the most recently cleared history. Individually deleted cards cannot be restored.
  • Clear Fields: clears current entry fields without affecting Saved History, settings, or workbook files.

8. Copying Rows

  1. Use Copy This Sheet Row on the Saved History card you want to copy. The exact A–M row is created from the saved record even though every field is not printed on the card.
  2. Use Copy All Sheet Rows for every Saved History record.
  3. Open Game Records and select the first empty cell in column A, beginning with A5. Selecting the row number can also work, but selecting the column-A cell is the recommended method.
  4. Keep the cell selected rather than entering cell-edit mode with a text cursor.
  5. Paste into column A only. The row fills columns A–M.
  6. Do not paste over formula columns N–Z.

9. Profitability Analysis Template

The v246.1 workbook has six sheets:

v246.1 layout update: The Summary title is merged and centered, and Game Records rows 1–4 are frozen so the totals and headers remain visible while scrolling. The calculation formulas and accounting rules are unchanged.
  1. Instructions — setup, carryover fields, and usage guidance.
  2. Game Records — editable inputs A–M and formulas N–Z.
  3. Record Review — highlights missing record information and mirrors Notes.
  4. Summary — exact counts, shares, and financial totals.
  5. Game Comparisons — a paid table for Member, Non-Member, Unclassified, and All Paid Games, plus a separate Free Game Chip Performance section.
  6. Best Results — top performance records.

Rows 5–504 are formula-ready record rows. Row 505 marks the archive boundary.

Updating from v245 or an older workbook

Use the current v246.1 workbook because the app and workbook now use the same two-decimal Profit/Draw comparison, while retaining the Free Game chips/game-credit separation. In the older workbook, copy only populated Game Records A5:M. In v246.1, select A5 and paste—preferably as values only. Paid results and Free Game rows recalculate automatically.

Do not copy the entire sheet, header rows, Summary, Game Comparisons, Instructions, or columns N–Z. Keep the older workbook as a backup until the transferred records and totals are verified.
Do not type over formula cells N–Z unless intentionally replacing the formula.

10. Totals and Comparisons

  • Running Net Game Profit: includes paid-game cash profit and paid Disqualified Entry Fees before membership fees; Free Game chips are excluded.
  • Gross Profit Earned: includes positive paid-game cash profit only.
  • Total Losses: includes paid Disqualified Entry Fees, not Free Game disqualifications.
  • Running Net Profit: Game Records column Z continues cash Net Profit row by row; Free Game rows leave it unchanged.
  • Actual Running Net Profit: Summary subtracts current and carryover membership fees from Running Net Game Profit.
  • Paid-game counts and ROI: exclude Free Games, Disqualified Free Games, and Subscription rows.
  • Free Game count and chips: Summary reports Free Games and Free Game Chips Earned separately without adding either to paid-game cash totals.
  • Free Game comparisons: Game Comparisons includes a separate Free Game Chip Performance section for completed and disqualified Free Games, chips earned, Eliminated Players, Elimination Rate, and All Completed Games. ROI remains N/A.

Summary and Game Comparisons use numerical tables rather than charts for easier mobile viewing and exact verification.

11. Subscriptions

Subscription rows are workbook-only non-game costs. Enter them directly in Game Records:

  • Payment / Record Type = Subscription
  • Entry Fee = annual or membership cost
  • Use N/A only for game-specific fields that do not apply

Subscription costs do not increase game counts or Running Net Game Profit. They increase Membership Fees and reduce Actual Running Net Profit.

12. Settings

The Help popup uses compact accordion sections so routine answers remain easy to scan. Calculate and Save is open by default; other topics open only when selected. Detailed workbook maps and reports remain in this document.

Settings auto-save. Available controls include Haptic Feedback, Help visibility, default-open sections, the $0 Entry Fee prompt, and Remember Game Entry inputs.

Restore Defaults asks for confirmation and does not delete Saved History, copied records, or workbook files.

13. Installation

StepCat works as a normal webpage and as an installable PWA on supported devices. From the hosted web version, use the compact Install StepCat strip near the top of the calculator. Tap Install when the browser offers native installation, or Not now to hide the strip for the current browser session.

When a native prompt is unavailable, the button changes to How to Install and opens Help → Guides & Downloads. The separate Add to Home Screen shortcut instructions remain in Help. The strip is hidden while StepCat is already running in installed-app mode, and no additional shortcut is needed.

14. Troubleshooting

Estimate looks lower than the Entry Fee

This is allowed. StepCat displays the exact estimate and applies Draw accounting rather than replacing it with the Entry Fee.

Calculate is disabled

Check for an End Date earlier than the Start Date. Correcting the dates re-enables Calculate & Save.

StepCat moved to another section

This is guided validation. StepCat uses one smooth guided scroll to the first control that prevents calculation and highlights it temporarily. A single correction occurs only when a mobile browser leaves the target outside the comfortable viewport area. Correct that control, then calculate again.

Result asks for Membership Type confirmation

Tap the desired Member or Non-Member side after entering the current record identity. The selector itself confirms the choice, and a compact inline strip displays the confirmed selection. A deliberate tap also confirms the already-selected remembered side. Confirmation resets when the record, Entry Mode, or Membership Type changes.

Copied row did not calculate

Confirm that the first empty cell in column A was selected before pasting, that the cell was not in text-edit mode, and that columns N–Z were not overwritten. Selecting the row number can also work, but selecting the column-A cell is recommended.

History was deleted

Clear History can be restored once. An individually deleted record is permanent.
