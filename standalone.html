1. Purpose and data-storage boundaries

Current workbook as of September 1, 2026: Workbook v253.4 is recommended with StepCat Calculator v253.1. Profitability calculations and report layouts remain unchanged. Workbook v253.4 adds normalized Payment / Record Type validation, burnt-orange / bronze completion cues for applicable missing A:L inputs, matching Record Review guidance, and continued backward compatibility with older Subscription-style membership records.

StepCat calculates projected payouts and records completed results. It stores Saved History locally and copies one exact A–M workbook row. The matching workbook calculates N–Z, reviews data quality, and builds reports.

Device storage: StepCat Saved History, settings, and unfinished fields remain in the current browser/device and do not transfer automatically. The Google Sheet is the permanent cross-device record.

Workbook independence: Workbook v253.4 can be maintained directly without StepCat. Enter or paste A–M and leave N–Z untouched; the workbook calculates results, review status, totals, and reports. Special workbook rows use Free Game / Chips and Membership Fee.

StepCat Calculator v253.1 retains protections for destructive actions, permanent SC Record IDs, Free Game validation, safe unfinished-entry recovery, startup-only drawer preferences, dynamic requirement labels, and compact help dialogs.

Release check: verify the hosted Google Sheets copy link, mobile migration pop-up, and device-local/cross-device guidance before publishing.

2. Four-step workflow

Progressive border cue: muted brown identifies a locked or unavailable workflow area, gold identifies the step or subsection to complete next, stronger gold identifies the selected choice, green identifies completed work, and red identifies something that must be corrected.

  1. Step 1 — Entry Mode: choose Estimate or Finalized from the divided two-choice control.
  2. Step 2 — Membership Type: confirm Member or Non-Member from the matching divided control.
  3. Step 3 — Game Entry: type only the values shown on the game platform. Game Details, Calculation Information, and Final Result are compact unnumbered subsections inside this one step.
  4. Use Continue to move forward between Step 3 subsections and Back to return to the preceding subsection. Completed earlier subsections remain available to reopen, while future subsections stay locked until Continue reaches them. Your entered values remain in place as you move between sections.
  5. Step 4 — Review, Calculate & Save: inspect all entered values together, edit any subsection if needed, then calculate and save.
  6. Copy the completed row to the workbook, or finalize an Estimate in place when the game ends.

The Guided Sections | Show All Fields switch expands the same Step 3 inputs without clearing them and can return to one-section-at-a-time viewing.

3. Entry Mode and Membership Type

Estimate

Estimate projects a likely payout from Gross Pot and Eligible Players. Non-Member estimates use the Adjusted Pot after the 15% deduction. Estimate cards show Estimated Earned, Accounting Result = N/A until finalized, and ROI = N/A.

Finalized

Finalized records a completed result. Final Earned determines Profit, Draw, or Disqualified accounting. Switching modes keeps the current unfinished entry; Start New Entry begins a different challenge.

Membership Type

Member uses the full Gross Pot. Non-Member uses 85% after the 15% deduction. Membership can optionally be remembered, but validation still requires a confirmed selection when nothing is remembered. The full Membership Type card is gold while Step 2 is current and green after confirmation. Show Math expands to display the complete Member or Non-Member formula. Its live example updates automatically from the Gross Pot and Eligible Players values entered in Step 3.

4. Game Entry fields and contextual help

ColumnsPurpose
A–FGame identity, dates, Entry Mode, Membership Type, and Payment / Record Type.
G–JGross Pot, Entry Fee, Eligible Players, and Total Players.
K–MFinal Earned / Chips, Disqualified / Lost Entry Fee, and Notes.

Game Entry is Step 3. Its unnumbered subsections are Game Details, Calculation Information, and Final Result. In Guided Sections, Continue is the only forward route and Back returns one subsection. The active subsection stays fully emphasized; completed earlier subsections collapse and dim but remain reopenable, while unreached future subsections are more strongly dimmed and cannot be opened by tapping their headers. Show All Fields displays the same labeled inputs together without clearing or duplicating values and hides the Guided Continue/Back controls because the complete form is already visible. Field labels keep the information button separate from the requirement label. Before Entry Mode is chosen, mode-dependent fields say Select Entry Mode. In Estimate, Gross Pot and Eligible Players say Required. Amount-entry fields accept at most two digits after the decimal; an additional decimal point or extra fractional digits are discarded. In Finalized, those fields say Optional while Final Earned / Chips says Required unless Disqualified is selected. Notes and Copied Date Format are part of Game Details. Copied Date Format is a StepCat setting and has no requirement badge. Required must be completed; Optional may be left blank and can still be entered for record or comparison details. During Game Entry, the first required field needing attention receives the gold current-action border.

6. Review, validation, and saving

Review Entry gathers the complete record before saving. Each review group includes an Edit action that reopens the exact Step 3 subsection. Calculate & Save is available inside the review rather than creating a record immediately.

Blocking errors use coordinated layers: an exact inline message beside the affected field, a flat informational summary in Step 4, and one short toast after a save attempt. StepCat opens the relevant Step 3 subsection and scrolls to the first invalid field.

  • Required fields must be present.
  • Eligible and Total Players must be whole numbers.
  • Eligible Players cannot exceed Total Players.
  • End Date cannot precede Start Date.
  • Finalized results require Final Earned unless Disqualified is selected.

Success toasts are brief; warnings and actionable errors remain slightly longer, while persistent inline messages stay until corrected.

Free Game rule: Free Game records must use a $0 Entry Fee in both Estimate and Finalized modes. StepCat blocks a non-zero fee before saving.

7. Saved History

Saved History persists locally and supports copy-one, copy-all, Clear History, and Restore History. Copy All Sheet Rows remains the primary action; the copy guidance appears next, followed by Restore History and Clear History as maintenance controls. Individual deletion now provides a brief Undo action. Every record has a stable non-editable SC-#### Record ID. Named records show it as secondary text; unnamed records use it in the fallback title and workbook Game Name.

Device boundary: Saved History and unfinished fields stay in the current browser/device. They do not automatically appear on another device or browser profile.

Each Estimate card includes a visible Finalize This Estimate action. This is the correct image for the Saved History section; it replaces the unrelated screenshot previously noted in Section 7 of the older guide.

8. Finalizing an Estimate without duplication

Finalize This Estimate updates the existing Saved History item, preserves its SC Record ID and chronological position, and scrolls to the record actually updated. Legacy Free Game Estimates with a non-zero fee are blocked until corrected.

Disqualified / Lost Entry Fee starts OFF and already means Not Disqualified. Do not toggle it merely to confirm “No.” Turn it on only when the record was actually disqualified. ON sets Final Earned to 0.00 and locks the field; returning it to OFF restores the Final Earned value that was present before the toggle, or restores a blank field when no value had been entered.

The current before-and-after SC-0004 screenshots in Sections 3 and 7 show the normal Estimate-to-Finalized path. The older finalization-dialog screenshot has been removed because its untouched OFF appearance predates the current explicit Not Disqualified state.

In the workbook, paste the finalized A–M row over the same game’s existing A–M cells. Do not add a second row for the same game.

9. Copying records and cross-device use

Use the workbook directly: StepCat is optional. Open the same Google Sheet on any device signed into the same Google account, enter or paste A–M, and let N–Z calculate automatically.

Completed records entered in the Sheet are available across devices. StepCat local Saved History, settings, and unfinished fields are not synchronized.

Getting the workbook: choose Open Workbook v253.4 in Google Sheets in Help & Resources. Workbook v253.4 is the current recommended workbook.

  1. In StepCat, use Copy This Sheet Row or Copy All Sheet Rows.
  2. Open Game Records and select the first empty cell in column A.
  3. Paste A–M. N–Z calculate automatically.

Older workbook migration: copy A5:M only through the last actual record row into Workbook v253.4 at A5. For example, if row 198 is the last record, copy A5:M198. You do not need to copy unused yellow rows down to the red boundary. Include any blank rows that occur between existing records so their order is preserved. On a computer use Paste special → Values only. On a phone or tablet, regular Paste is acceptable when only A–M are copied; minor A–M appearance differences can be corrected later.

Never copy: N–Z, headers, entire rows, entire sheets, reports, or charts.

10. Workbook structure and direct entry

Independent operating mode: the workbook is a self-contained recordkeeping and profitability system. The calculator provides guided entry, validation, local history, and convenient A–M copying, but is not required for the workbook formulas or reports.

Instructions and color coding

Every instructional row is assigned a consistent visual category. Rows 17–18 have sufficient height and wrapping. The calculations section now flows directly from Profit to Draw with no hidden spacer row. Major sections are separated by deliberate white space, the What’s New area uses one orange header, Google Sheets workflow uses a blue section header, and compatibility and release-safety notes use green.

Game Records

A:M are pale-gold user inputs, with burnt orange / bronze used only for applicable required A:L fields that are still missing after a record has been started. N:Z keep a pale-blue calculated/protected background. Result meaning in N:Z is shown by number/text color: green for Profit, dark/black for Draw or zero, and red for Loss, including a paid disqualification. Estimate timing/status cells in C and D retain their separate status colors. Row 4 is taller so wrapped headers are not clipped. Numeric input columns G–K are right-aligned, including N/A text used for non-applicable values.

Mobile row insertion: to add a record between existing records, insert a whole worksheet row above the desired position and enter or paste A–M. The red ACTIVE RECORD BOUNDARY moves down temporarily. After inserting rows, delete the same number of unused blank rows immediately above the red boundary so it returns to row 505. Never delete the red boundary itself.

Record Review

Record Review specifically flags Free Game rows with a non-zero Entry Fee. Valid Free Game rows with a $0 fee receive no contradiction warning.

11. Reports, fees, and Record Review

Games by Result uses exact counts for Profit, Draw, and Disqualified completed paid games. Membership Fee rows are excluded from game-result counts and tracked separately. Actual Running Net Profit subtracts those non-game costs from Net Game Profit. The v253.1 reporting update added meaningful complementary Best Results records for positive profit and ROI, low/high elimination rates, shortest/longest challenge, largest player field, most players eliminated, largest paid-game Gross Pot, and highest Free Game chips. A true 0% elimination rate is treated as a valid record rather than a blank.

12. Settings and Restore Defaults

Setting changes save automatically. Default-open choices apply only when StepCat loads or refreshes; they do not reset live drawer states while the user works. Restore Defaults is a confirmed bulk action that replaces saved preferences with StepCat’s original settings, including Haptic Feedback set to Low. It does not delete Saved History, current entry information, or spreadsheet records. Informational popups use one large Close button.

  • Show Help Button, Show Installation Prompt, and Show Spreadsheet Copy Instructions.
  • Control the starting state of Game Entry, Saved History, and the nested Spreadsheet Copy Instructions disclosure.
  • Remember Estimate / Finalized Mode, Game Entry Layout, Membership Choice, Payment / Record Type, Unfinished Entry, and Open Help & Guide Sections.
  • Confirm Before Saving a $0 Entry Fee.
  • Haptic Feedback is separate from Help & Feedback.

Remember Game Entry Layout independently controls whether Guided Sections or Show All Fields returns after reload. Disqualified is never remembered for a new entry.

Remember unfinished Game Entry inputs stores only unfinished work. Successful saves keep the completed entry visible for review. Start New Entry performs the deliberate reset, and Disqualified never returns through draft recovery.

13. Help, guides, installation, and feedback

Each Quick Explanation header includes a short helper line, followed by one state-aware Expand All / Collapse All control. The Color Guide explains workflow highlights and Saved History outlines without relying on color alone. Help & Resources provides one supported workbook action: Open Workbook v253.4 in Google Sheets, plus a compact Move your records pop-up for earlier-version users. Remember Open Help & Guide Sections is shared by Settings and the Quick Start Guide. Using the Workbook also explains direct workbook entry, cross-device use through Google Sheets, and the device-local limits of StepCat Saved History.

Installation & Shortcuts

The state-aware Install StepCat card shows Install StepCat when a browser prompt is available, Installation unavailable in a local or unsupported context, and is hidden when the app is already installed. Detailed platform methods are behind the information button. It opens a compact dialog with one large Close control instead of navigating into Help & Resources.

Feedback

The main Write Feedback action uses the same orange gradient and light text as Show Math, with its title and helper text centered at every responsive width. It opens a dialog, copies the message, and attempts to prepare an email. Browser or device restrictions may affect whether the email app opens.

14. Migration from earlier workbooks

Workbook v253.4: the What’s New card at the top of StepCat summarizes the September 1 completion-cue and validation update. The current details are reproduced in this guide, so no representational screenshot is substituted for the live card.

As of September 1, 2026, Workbook v253.4 is the recommended workbook. It retains the established profitability formulas and reporting structure while adding completion cues and field-review consistency. Earlier corrected workbooks can continue to perform the core calculations, so migration is not mandatory solely because Workbook v253.4 exists. Updating is strongly recommended for copies that predate the August 11 corrections or show formula/reference problems.

  1. Keep the older spreadsheet as a backup.
  2. If you choose or need to update, open Workbook v253.4 in Google Sheets and make your own editable copy if desired.
  3. Transfer A5:M only through the last actual record row—for example, A5:M198 if row 198 is the last record. Do not copy unused yellow rows down to the red boundary; include any blank rows that occur between existing records.
  4. Use Paste special → Values only on a computer, or regular Paste on mobile when only A–M are selected.
  5. Do not copy N–Z, headers, whole rows, whole sheets, reports, or charts.
  6. No Carryover is needed merely to update. Carryover is for starting a fresh workbook after all 500 active record positions are actually filled.
  7. Verify the first and last records, record count, Summary, Record Review, and Best Results.

15. Troubleshooting

Game Entry feels too long

Step 3 keeps one compact subsection open at a time. Choose Continue to move forward; use Back to return one subsection. Completed earlier sections are dimmed but can be reopened, while future sections remain more strongly dimmed and locked until reached. StepCat does not automatically scroll, focus fields, or open the keyboard when a subsection appears. Use the compact Show All Fields button whenever you prefer the complete form; returning to Guided Sections does not clear values.

I want to check everything before saving

Open Review Entry in Step 4. The complete record appears together, and each group has an Edit action that returns to the exact Step 3 subsection.

Switching between a phone and computer

Open the same Google Sheet from the other device. Records already entered in the Sheet are available there. StepCat Saved History, settings, and unfinished fields remain on the original browser/device and must be copied to the Sheet before switching.

Calculate does not continue

Correct the highlighted inline fields. Step 4 opens the relevant Step 3 subsection and identifies the first value needing attention.

Membership or Entry Mode reset

Enable the corresponding remembered Estimate / Finalized Mode or Membership Type setting. If it remains off, a fresh confirmation is intentional.

Estimate is below the Entry Fee

The card still shows the exact projection. Estimated Break-Even Point gives the relevant eligible-player count; finalized accounting remains N/A.

Moving older records

An August 11 corrected v253.0 workbook may remain in use if it is calculating normally. If your copy predates those corrections, shows formula/reference problems, or you want the finalized Workbook v253.4 presentation, copy A5:M only through the last actual record row into Workbook v253.4 at A5. For example, if row 198 is the last record, copy A5:M198; unused yellow rows below it do not need to be copied. A computer is easiest; regular mobile Paste is acceptable when only A–M are copied. Do not copy N–Z or whole rows/sheets. No Carryover is needed merely to update.

Inserting a missing record on mobile

Insert a whole worksheet row above the desired position, then enter or paste A–M. The red boundary moves down temporarily. Afterward, delete the same number of unused blank rows immediately above the red boundary to return it to row 505. Never delete the red boundary itself.

Installation unavailable

Open the hosted page in a supported browser or use the information button for Add to Home Screen methods.

Free Game fee is rejected

Free Game records require a $0 Entry Fee. Change the fee to 0 or use another Payment / Record Type.

A saved entry returned as an unfinished draft

StepCat v253.1 keeps completed fields visible after a successful save. Use Start New Entry when you are ready to reset the form.

A drawer changed after opening Settings

v253.1 preserves live drawer state. Default-open settings apply on the next load or refresh.

16. Release and workbook requirements

StepCat Calculator v253.1 is paired with the current Workbook v253.4. Earlier corrected workbooks may continue to perform the core calculations, but Workbook v253.4 is recommended because it keeps the established reporting and mobile-workflow behavior while adding normalized Payment / Record Type validation, burnt-orange / bronze completion cues for applicable missing A:L inputs, and matching Record Review guidance. The current workbook provides 500 active record positions, normally rows 5–504. Whole-row insertions above the red boundary can move it temporarily; after inserting, remove equivalent unused blank rows immediately above the boundary so it returns to row 505. Enter or transfer records through A–M only and leave N–Z to the workbook’s protected formulas. Older records transfer through A–M values only, stopping at the last actual record row; unused yellow rows down to the boundary do not need to be copied.
