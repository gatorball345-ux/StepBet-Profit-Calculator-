Modes & Membership
Estimate
Projects a likely payout from Gross Pot and Eligible Players. It does not post cash accounting until finalized.
Finalized
Records the completed amount actually returned.
Member
Uses the full Gross Pot.
Non-Member
Uses 85% of Gross Pot after the 15% deduction.
Guided entry: Entry Mode is Step 1 and Membership Type is Step 2. Their separate Remember settings control whether those choices return after refresh.
Saved History
  • SC Record ID: permanently identifies the record and is not a spreadsheet row number.
  • Copy This Sheet Row: copies one exact A–M workbook row.
  • Copy All Sheet Rows: copies every saved record.
  • Delete: removes one card and briefly offers Undo.
  • Clear History: creates a dated history backup before clearing all cards.
  • Restore History: warns before replacing non-empty current history.
  • Restore Cleared Fields: restores only the most recently cleared entry form.
Workbook & Copying

Getting the workbook: tap Make a Google Sheets Copy, then choose Make a copy.

  • New record: paste into the first empty Game Records column-A cell, such as A5.
  • Finalized Estimate: paste the finalized A–M values over the same game’s existing A–M worksheet cells.
  • Protect formulas: paste or edit only in A–M; never clear or overwrite N–Z.
Rules & Troubleshooting

Result Rules

  • Profit: Final Earned is above Entry Fee.
  • Draw: a normal completed result at or below Entry Fee; Net Profit is $0.00.
  • Paid Disqualification: Final Earned is $0.00 and the full Entry Fee is lost.
  • Disqualified Free Game: status is recorded with $0.00 monetary loss.
  • Free Game: Entry Fee must be $0. A non-zero fee is blocked. ROI is N/A.
Estimate Accuracy
  • Add a new challenge after warm-up week ends.
  • Update Eligible Players as the challenge progresses.
  • Total Players adds context; Eligible Players drives the estimate.
  • A below-fee Estimate remains a projection and does not affect cash totals until finalized.
Common Fixes
  • Dim Game Entry: choose Entry Mode, then confirm Member or Non-Member.
  • Calculation pauses: tap Calculate & Save to highlight the first missing or invalid requirement.
  • End Date: it must be the same as or later than Start Date.
  • Locked Final Earned: turn off Disqualified to edit it.
  • Settings: ordinary changes save automatically; Restore Defaults returns Haptic Feedback to Low.
  • Old cached page: close older StepCat tabs, then reload the hosted v252 page.

Spreadsheet Copy Help

Tap to show or hide paste instructions.

Copy one record

  1. Tap Copy This Sheet Row on the saved card.
  2. Open Game Records in the current Profitability Analysis Template.
  3. For a new record at the end, select the first empty cell in column A, such as A5, and paste.
  4. For a forgotten game, select a cell inside the native Google Sheets table and insert a row above or below at the correct location, then paste into column A.

Recommended: select the column-A cell itself—not cell-edit mode. Record Review will warn if a populated record is missing one or more formulas in N–Z.

Protect the formulas: paste or edit in A–M only. Never clear or overwrite N–Z, because those columns calculate automatically.

Copy more than one record

Use Copy All Sheet Rows in Saved History, then paste the block beginning in the first empty column-A cell.

Special cases and column notes

Workbook totals: Game Records shows Running Net Game Profit, Gross Profit Earned, and Total Lost Entry Fees at the top. Summary shows Actual Running Net Profit after membership fees. Column Z tracks Running Net Profit row by row.

Current workbook: v252 uses automatic inserted-row formulas, visible cell borders, Free Game safeguards, disqualified $0.00 values, and Record Review warnings. Estimate rows show Result = Estimate and N/A in accounting columns P–W while Running Net Profit carries forward unchanged. When migrating, compare the older A–M headers with v252 and copy populated values only; never copy whole sheets, headers, Record Review, or N–Z.

Formula recovery: if Record Review reports missing formulas, undo the insertion and insert the row again from inside the Game Records table. If formulas still do not appear, copy N–Z from an adjacent working row into the new row, then verify the calculated result and warning in Record Review.

Workbook capacity: rows 5–504 are formula-ready. Row 505 marks the archive boundary.

Notes: optional Notes copy into column M. Hybrid cash-and-points details belong there.

Below-fee Estimates: the exact projected amount appears in formula column O; Final Earned remains blank.

Free Games: in the workbook choose Free Game — completed challenge/chips. When estimate inputs are unavailable, columns N and O display N/A. ROI remains N/A; recorded chips appear separately and never increase cash-profit totals.

Disqualified rows: Final Earned copies as $0.00 and Disqualified / Lost Entry Fee copies as Yes. Paid entries lose the full Entry Fee; Free Games record no monetary loss.

Annual membership: in the workbook choose Subscription — membership charge only and enter the annual cost in Entry Fee. Subscription rows are non-game expenses.

Other spreadsheet apps: copied rows can be used for basic recordkeeping, but only the StepCat template includes the built-in formulas and reports.
