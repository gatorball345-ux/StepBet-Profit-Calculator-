Start Here

The everyday StepCat workflow.

Calculate and Save
  1. Choose D · Entry Mode: Estimate or Finalized.
  2. Confirm E · Membership Type by tapping Member or Non-Member. Game Entry fields then brighten and activate.
  3. Enter the requested information. Small A–M badges match the workbook columns.
  4. Watch the status below Calculate & Save. It brightens when every required field for the selected mode is ready.
  5. Tap Calculate & Save. The newest Saved History card opens automatically.
  6. Tap Copy This Sheet Row when you are ready to paste the record into the workbook.
Modes & Membership
Estimate
Projects a likely payout from Gross Pot and Eligible Players. It does not post cash accounting until finalized.
Finalized
Records the completed amount actually returned.
Member
Uses the full Gross Pot.
Non-Member
Uses 85% of Gross Pot after the 15% deduction.
Guided entry: Membership Type is the gate for each new record. After Clear Fields or a page refresh, tap Member or Non-Member again—even when remembered values or the remembered selector position remain visible.
Finalize the existing worksheet row: when an estimated game ends, switch to Finalized, copy the completed A–M values, and paste them over that game's existing worksheet A–M cells. Do not add a second worksheet row for the same game; it could be counted twice.
Saved History
  • Card display: shows each essential value once; Payment / Record Type and Entry Fee are separate when applicable.
  • Pot details: Gross Pot and any Non-Member deduction/Adjusted Pot values appear directly with the other card details.
  • Copy This Sheet Row: copies one exact A–M workbook row.
  • Copy All Sheet Rows: copies every saved record.
  • Delete: removes one card and offers a brief Undo action.
  • Clear History: clears all cards but keeps one history-only restore backup.
  • Restore History: restores the most recently cleared history. Individual deletion uses its own brief Undo action.
  • Restore Cleared Fields: restores only the most recently cleared entry form. It never restores or changes Saved History.
Workbook & Copying

Getting the workbook: tap Make a Google Sheets Copy, then choose Make a copy. Do not use Save As; no file format is required. My Drive is the default destination, and the displayed folder names in the guide are privacy-safe examples.

Open Spreadsheet Copy Help below Calculate & Save for the three-step paste process.

  • Copy one: use Copy This Sheet Row on its Saved History card.
  • Copy all: use Copy All Sheet Rows in Saved History.
  • New game: paste into the first empty Game Records column-A cell, such as A5.
  • Finalizing an estimate: paste the finalized A–M values over the same game's existing A–M worksheet cells. Do not add a second row for that game.
Protect the formulas: paste or edit in A–M only. Do not clear or overwrite N–Z.

Rules & Troubleshooting

Result Rules

  • Profit: Final Earned is above Entry Fee.
  • Draw: a normal completed result at or below Entry Fee; Net Profit is $0.00.
  • Paid Disqualification: Final Earned is $0.00 and the full Entry Fee is lost.
  • Disqualified Free Game: status is recorded with $0.00 monetary loss.
  • Free Game: ROI is N/A; any positive return is chips/game credit and does not count as cash profit.
Estimate Accuracy
  • Add a new challenge after warm-up week ends.
  • Update Eligible Players as the challenge progresses.
  • Total Players adds context; Eligible Players drives the estimate.
  • A below-fee estimate remains visible, but Estimate accounting stays N/A and does not affect cash totals until finalized.
Common Fixes
  • Dim Game Entry: tap Member or Non-Member to activate the A–M fields.
  • Calculation pauses: tap the dim Calculate & Save button to scroll to and highlight the first missing or invalid requirement.
  • End Date: it must be the same as or later than Start Date.
  • Locked Final Earned: turn off Disqualified to edit it.
  • Settings: use Restore Defaults; Cancel keeps current settings and Confirm resets them.
  • Old cached page: close older StepCat tabs, then reload the current package or hosted page.

Spreadsheet Copy Help

Tap to show or hide paste instructions.

Copy one record

  1. Tap Copy This Sheet Row on the saved card.
  2. Open Game Records in the current Profitability Analysis Template.
  3. For a new record at the end, select the first empty cell in column A, such as A5, and paste.
  4. For a forgotten game, select a cell inside the native Google Sheets table and insert a row above or below at the correct location, then paste into column A.

Recommended: select the column-A cell itself—not cell-edit mode. Record Review will warn if a populated record is missing one or more formulas in N–Z.

Protect the formulas: paste or edit in A–M only. Never clear or overwrite N–Z, because those columns calculate automatically.

Copy more than one record

Use Copy All Sheet Rows in Saved History, then paste the block beginning in the first empty column-A cell.

Special cases and column notes

Current workbook: v251.1 uses automatic inserted-row formulas, visible cell borders, Free Game safeguards, disqualified $0.00 values, and Record Review warnings. Estimate rows show Result = Estimate and N/A in accounting columns P–W while Running Net Profit carries forward unchanged. When migrating, compare the older A–M headers with v251.1 and copy populated values only; never copy whole sheets, headers, Record Review, or N–Z.

Formula recovery: if Record Review reports missing formulas, undo the insertion and insert the row again from inside the Game Records table. If formulas still do not appear, copy N–Z from an adjacent working row into the new row, then verify the calculated result and warning in Record Review.

Workbook capacity: rows 5–504 are formula-ready. Row 505 marks the archive boundary.

Notes: optional Notes copy into column M. Hybrid cash-and-points details belong there.

Below-fee Estimates: the exact projected amount appears in formula column O; Final Earned remains blank.

Free Games: in the workbook choose Free Game — completed challenge/chips. When estimate inputs are unavailable, columns N and O display N/A. ROI remains N/A; recorded chips appear separately and never increase cash-profit totals.

Disqualified rows: Final Earned copies as $0.00 and Disqualified / Lost Entry Fee copies as Yes. Paid entries lose the full Entry Fee; Free Games record no monetary loss.

Annual membership: in the workbook choose Subscription — membership charge only and enter the annual cost in Entry Fee. Subscription rows are non-game expenses.

Other spreadsheet apps: copied rows can be used for basic recordkeeping, but only the StepCat template includes the built-in formulas and reports.
