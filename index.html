Help / Quick Guide

Quick app reference.

What StepCat Does

  • Tracks entries, payouts, draws, and disqualifications.
  • Creates sheet-ready rows.

Result Rules

  • Profit: Earned above Entry Fee.
  • Draw: Earned equal to or below Entry Fee, unless Disqualified / Lost Entry Fee is marked Yes.
  • Disqualified / Lost Entry Fee: Final Earned copies as $0.00 and the workbook counts the full Entry Fee as lost.
  • Loss note: StepCat does not count partial losses for normal completed challenges; only disqualification records a loss.

Entry Modes

  • Estimate: projected result.
  • Finalized: completed result.
  • Use Disqualified only when the full Entry Fee was lost. StepCat uses $0.00 Final Earned and marks the copied row as Disqualified / Lost Entry Fee: Yes.

Estimate Accuracy

  • Add new challenges after warm-up week ends.
  • Update Eligible Players as the challenge progresses.
  • Total Players is useful context, but Eligible Players drives the estimate.

StepCat App vs. Profitability Analysis Template

  • StepCat App: best for quick mobile calculations, saved recent results, and copying clean spreadsheet rows.
  • Workbook Template: best for long-term tracking, finalized updates, summaries, comparisons, best results, and spreadsheet analysis.
  • You can use either one by itself, but they work best together: calculate in StepCat, then paste into the template for full tracking.

Copying Rows

  • Download the current StepCat Profitability Analysis Template.
  • After calculating a game, tap Copy This Sheet Row to copy one game as one spreadsheet row.
  • In Saved History, Copy All Sheet Rows copies every saved result as multiple spreadsheet rows.
  • Paste each copied row into the next available row in the Game Records tab, beginning with A5. Paste into column A only.
  • The copied row fills input columns A through M. Formula columns N through Z calculate the deeper tracker results.
  • Annual membership rows are non-game costs. Select Payment / Record Type = Subscription, enter the annual membership cost in Entry Fee on that row, and use N/A only for game-specific fields.

Workbook Setup

  • Workbook template: add or update games under the matching column names.
  • A through M: user-editable input columns copied from the app.
  • N through Z: formula columns for Adjusted Pot, Estimated Earned, Result Earned, Profit, Draw, Lost, ROI, Result, Challenge Length, Net Profit, Eliminated Players, Elimination Rate, and Running Net Profit.
  • Result Earned: the earned amount used to determine Profit, Draw, Disqualified loss, ROI, and Result.
  • Do not type over formula cells unless you intentionally want to replace the formula.
  • For estimates, Final Earned stays blank. A finalized value or Disqualified status can be entered directly in the spreadsheet when known.

Yellow Workbook Fields

  • Yellow dashed cells mark record fields that currently have no value.
  • They are a visual convenience, not a warning and not an indication that the information exists elsewhere.
  • Record Review lists highlighted fields and mirrors anything entered in Game Records Notes. Edit Notes only in Game Records.

Workbook Numerical Summaries

  • Summary: shows exact result counts, shares, financial totals, and the running tally.
  • Game Comparisons: shows exact Member, Non-Member, Unclassified, and All Completed Games statistics.
  • No charts or helper sheet: numerical tables are used for clearer mobile viewing and easier verification.
  • Notes: copied Notes cells remain blank unless you enter a note yourself.
  • Workbook capacity: Game Records provides exactly 500 usable record rows, from row 5 through row 504. Row 505 is a clearly marked archive boundary; do not enter records beneath it.
  • Carryover Setup: when continuing from an archived workbook or starting midyear, enter the prior net game profit, prior membership/subscription costs, and prior completed-game count on the Instructions sheet. Column Z and the row 1 banner continue from that amount.
  • Yellow input cells: every editable A:M cell is yellow and can be tapped for manual entry. Entry Mode, Game Type, Payment / Record Type, and Disqualified status provide dropdown choices.
  • Calculation logic: Member games use 100% of Gross Pot; Non-Member games use 85%. Estimated Earned is Adjusted Pot divided by Eligible Players. A finalized amount above Entry Fee is Profit; a normal amount at or below Entry Fee is a Draw; Disqualified records the full Entry Fee as lost.
  • Subscription verification: Payment / Record Type is authoritative. A row marked Subscription must not increase game counts or Column Z; its Entry Fee amount must increase Membership Fees and reduce Actual Running Net Profit.
  • Annual membership: select Payment / Record Type = Subscription and enter the annual cost in Entry Fee. The row is excluded from completed-game counts and tracked separately as a non-game expense.

Sheet Row Contents

  • Copy This Sheet Row: copies one calculated or saved game as one spreadsheet row.
  • Copy All Sheet Rows: copies every saved history item as multiple spreadsheet rows.
  • Copied rows fill the workbook template input columns A through M. The Notes cell is left blank unless you enter a note yourself.
  • That means StepCat pastes into columns A through M. Formula columns N through Z stay in place and calculate from those inputs.
  • For estimates, Final Earned stays blank. The spreadsheet uses Estimated Earned unless a finalized amount is entered.
  • For Disqualified rows, Final Earned copies as $0.00 and Disqualified / Lost Entry Fee copies as Yes. The workbook then counts the full Entry Fee as lost.
  • Annual membership rows are not games. Payment / Record Type = Subscription is the authoritative classification; enter the annual cost in Entry Fee and use N/A only in game-specific fields that do not apply.

Clear Card vs Delete

  • Clear Card: removes the visible result card only. Saved History is not deleted.
  • Delete: permanently removes that saved history entry.
