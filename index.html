Profitability Analysis template: use this main row order: Game Name, Start Date, End Date, Payment Type, Entry Fee, Earned, Profit, Draw, Lost, ROI, Result. Leave the header-row option off when pasting result rows into an existing sheet.

Earned is the total amount returned, including the recouped Entry Fee and any Profit. Profit is the extra amount won above the Entry Fee. Draw shows the Entry Fee recouped. Lost shows the Entry Fee forfeited when Disqualified.

Older spreadsheet rows: entries added before using StepCat may need spreadsheet formulas if ROI or Result were left blank. StepCat exports calculated values for new rows, but it cannot update rows already pasted into your spreadsheet.

Quick Start & Documentation

Use these links to learn StepCat, download the guide, or review the complete documentation.

  1. Choose Estimate or Finalized.
  2. For Estimate, choose Member or Non-Member, then enter Gross Pot, Entry Fee, and Eligible Winners. Non-Member estimates subtract 15% from the full pot; Member estimates use the full pot. Total Players is optional.
  3. For Finalized, confirm the remembered Game Type, then enter Entry Fee and the Official Earned Amount. The official posted amount is authoritative. Pot and winner information are not required for the finalized calculation.
  4. Tap Calculate & Save. A return equal to or below the Entry Fee is recorded as a Draw unless Disqualified / Lost Entry Fee is enabled.
  5. Use Copy Header in Saved History to set up row 1. Use Copy Latest Row for everyday entries, or Copy All Saved Rows to copy every saved result.

Spreadsheet & Profitability Tools

The updated template turns completed StepCat records, older manual entries, and in-progress games into a longer-term game analysis.

StepCat calculates before you paste: Adjusted Pot, Earned, Profit or Draw/Lost amount, ROI, and Result.

The updated template calculates after you paste or update a row: Challenge Length, Net Profit, Eliminated Players, and Elimination Rate. Summary, Game Comparisons, and Best Results update from the completed records. It does not recalculate Adjusted Pot.

For everyday use, copy the newest result and paste it into the next empty row. Use Copy All Saved Rows only for a first import or batch transfer; repeatedly pasting the same full history creates duplicates.
