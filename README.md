# StepCat Calculator v253.1

StepCat is an independent, mobile-first calculator and recordkeeping tool for step-challenge payout tracking. It can create payout estimates, record official completed results, keep device-local Saved History, and prepare exact A:M input rows for the matching profitability workbook.

**Current recommended pairing:** StepCat Calculator **v253.1** + Workbook **v253.4**, dated **September 1, 2026**.

- Live app: https://stepcat.netlify.app/

## Workbook v253.4

Workbook v253.4 is a completion-cue and validation-consistency update to the established StepCat profitability workbook. **Calculator math and workbook profitability calculations are unchanged.**

The September 1 update includes:

- **Burnt-orange / bronze completion cues:** after a record is started, applicable missing required inputs in A:L are highlighted; untouched rows remain pale yellow / cream and Notes (M) remains optional.
- **Record Review parity:** the review sheet reports the same applicable missing fields, including Game Name and finalized Free Game disqualification status.
- **Normalized Payment / Record Type validation:** the active record area uses consistent validation while preserving Membership Fee and Free Game / Chips exceptions.
- **Backward compatibility:** older Subscription-style membership records remain recognized by workbook formulas and checks.
- **Existing reporting retained:** Summary, Game Comparisons, Best Results, mobile row insertion, and the 500-record boundary workflow remain intact.
- **Current documentation:** browser guides, PDF, and editable DOCX have been updated for Workbook v253.4 with current public-blank workbook illustrations and current release text.
- **Enlargeable browser illustrations:** screenshots in the browser Quick Start Guide and Full Documentation can be tapped or clicked for a larger view.

## Four-step StepCat workflow

1. **Entry Mode** — choose Estimate or Finalized.
2. **Membership Type** — choose Member or Non-Member.
3. **Game Entry** — complete Game Details, Calculation Information, and, when applicable, Final Result.
4. **Review, Calculate & Save** — inspect the full entry, edit any section if needed, then save one record.

Guided Sections shows one Step 3 subsection at a time. Show All Fields displays the whole Step 3 form for scrolling. Switching layouts does not clear values.

The Final Result disqualification control is written as **Disqualified: No / Yes**. No is the normal default; choose Yes only for an actual disqualification/lost entry fee.

## Result rules

| Result | Rule |
| --- | --- |
| **Profit** | Final Earned is greater than Entry Fee; Net Profit is the difference. |
| **Draw** | A normal completed paid game returning the Entry Fee or less records $0.00 Net Profit while preserving the exact payout. |
| **Disqualified** | A paid entry records $0.00 Final Earned and loses the full Entry Fee. |
| **Free Game** | Return is chips/game credit; cash Net Profit is $0.00 and ROI is N/A. |
| **Estimate** | Projection only; finalized accounting remains unavailable until finalization. |

## Saved History

Saved History remains local to the current browser/device.

- Every saved record receives a stable **SC-####** Record ID.
- **Copy This Sheet Row** copies one exact A:M workbook row.
- **Copy All Sheet Rows** copies all saved A:M rows without a header row.
- **Finalize This Estimate** updates the same Saved History record rather than creating a duplicate.
- For durable cross-device storage, paste completed records into the Google Sheet.

## Profitability workbook

Workbook v253.4 can be maintained directly with or without the calculator.

### A:M are inputs; N:Z are protected calculations

- Enter or paste record values only in **A:M**.
- Do not edit, paste into, clear, or copy **N:Z**.
- N:Z are generated by protected expanding formulas anchored above the record area.
- N:Z keep their pale-blue calculated/protected background. Result meaning is shown by number/text color: green for Profit, dark/black for Draw or zero, and red for Loss, including a paid disqualification.
- The workbook normally provides **500 active record positions**, rows **5-504**, with the ACTIVE RECORD BOUNDARY at row 505.

### Moving records into Workbook v253.4

You do not need to migrate solely because v253.4 exists if an earlier corrected workbook is working normally. If you want the current validation/completion-cue improvements or are replacing an older/problematic copy:

1. Open Workbook v253.4 and make your own editable copy if desired.
2. In the older workbook, select **A5:M through the last row that actually contains a record**.
3. On desktop, paste with **Paste special -> Values only**.
4. On phone/tablet, regular Paste is acceptable when only A:M was copied.
5. Do **not** copy N:Z, headers, entire sheets, reports, charts, or unused yellow rows down to the red boundary.
6. Confirm the destination N:Z calculations and reports populate normally.

**Carryover is not required merely to update workbook versions.** Carryover is an alternative for starting a fresh record list without transferring prior Game Records rows. Prior Game Count includes completed games only; Membership Fee rows and unfinished Estimate rows are excluded.

### Inserting a record between existing rows

Insert a whole worksheet row at the destination, enter or paste A:M, and verify N:Z populate. If the red boundary moves below row 505, remove the same number of unused blank rows immediately above the boundary to return it to row 505. Never delete the boundary row itself.

## Reports

Workbook v253.4 includes:

- **Record Review** — game index, Estimate finalization/review status, fields that may deserve review, and compact review totals.
- **Summary** — game/result counts, Running Net Game Profit, Membership Fees, Actual Running Net Profit, and Free Game chip totals.
- **Game Comparisons** — Member, Non-Member, Unclassified, All Paid Games, and separate Free Game chip performance.
- **Best Results** — live highs, lows, and record extremes from Game Records.

Membership Fee rows are excluded from game-result counts and are subtracted separately when Actual Running Net Profit is calculated.

## Offline / PWA behavior

Install StepCat while connected. After the initial download, the calculator, Saved History, Settings, Help, and cached guides can load from the device. Internet access is still required for installation/updates, Google Sheets, downloads, feedback email, and external links.

Saved History is device-local and can be removed by clearing app/site data. The Google Sheet should be treated as the durable cross-device record.
