StepCat Quick Start Guide

Quick Start • Action Guide

StepCat v246.3.5

Calculate projected or finalized challenge results, save recent records, and copy workbook-ready rows.

1. Choose Entry Mode

Estimate

Use before the official result is available. StepCat calculates the projected return from Gross Pot and Eligible Players.

Finalized

Use after the official total returned is known. Tap Member or Non-Member to select and confirm that side before saving; no separate confirmation button is needed.

2. Choose Membership Type

Non-Member

StepCat subtracts 15% from Gross Pot before dividing by Eligible Players.

Member

StepCat uses 100% of Gross Pot.

Tap the desired Member or Non-Member side to confirm Membership Type for the current record. A compact inline strip confirms the selection in both Estimate and Finalized modes. For a Finalized record, Membership Type affects the Reference Estimate; the official result still comes from Final Earned Amount.

3. Enter the record

  1. Add Game Name, dates, and Payment / Record Type when available.
  2. Common payment descriptions include Cash, Points, Hybrid, and Free Game. Free, Free Game, and Free Entry are copied as Free Game; other descriptions are accepted.
  3. Use the optional Notes field for details such as a Hybrid breakdown: Original entry: $13.85 cash and 26.15 points.
  4. For Estimate, enter Entry Fee, Gross Pot, and Eligible Players. Total Players is optional context. When both Eligible Players and Total Players are supplied, the workbook calculates Eliminated Players and Elimination Rate, including for Free Games.
  5. For Finalized, enter Entry Fee and Final Earned Amount. For a Free Game, Final Earned is the number of chips/game-credit units awarded. Gross Pot and player counts are optional Reference Estimate data.
Disqualified / Lost Entry Fee: the compact Settings-style gold/red toggle in the framed Finalized Status panel clearly shows Not Disqualified or Disqualified. For a paid game, StepCat uses $0.00 Final Earned and records the full Entry Fee as lost. For a Free Game, it records the disqualification but no monetary loss.

4. Understand results

Profit

Final or estimated return is above Entry Fee. Profit is the amount above the fee.

Draw

A normal return equal to or below Entry Fee is treated as a Draw, with $0.00 Profit/Loss and 0.0% ROI. v246.3 rounds the payout-minus-fee difference to two decimal places before deciding Profit or Draw, so a displayed $0.00 difference is always a Draw.

Below-fee Estimate

The exact calculated estimate remains visible, even though Draw accounting keeps Profit/Loss at $0.00.

Free Game

A $0 Entry Fee records chips/game credit rather than cash. ROI is N/A, and chips are excluded from every cash-profit total.

5. Calculate and save

  1. Correct any inline date warning before continuing.
  2. Tap Calculate & Save.
  3. When something is missing or invalid, StepCat opens the relevant section, uses one smooth guided scroll with a single fallback check for mobile browsers and preview windows, and temporarily turns the target field light with a gold outline.
  4. StepCat opens the newest Saved History card automatically.
  5. Review the compact outcome, key amounts, and essential record details on that card. Payment / Record Type and Entry Fee appear as separate lines when applicable.
  6. When pot information is available, Gross Pot and any Non-Member deduction/Adjusted Pot lines appear directly with the other card details.
  7. Tap Copy This Sheet Row on the same card when ready. The exact A–M row is copied without displaying every spreadsheet field.
There is no separate Result Card or Sheet Row Preview. Saved cards stay compact while the copy action retains the complete workbook row. Delete removes one saved card permanently; Clear History keeps one restore backup.

6. Copy into the workbook

Workbook v246.3.5: the webpage still copies the identical A–M row structure. The workbook keeps the clearer Free Game and Subscription choices, improves completed Free Game reporting, prevents wrapped Record Review text from being clipped, and lists games continuously without Subscription gaps. Game Records IDs now match the sequential Game #.
  1. Download workbook v246.3.5.
  2. Tap Copy This Sheet Row on one Saved History card, or Copy All Sheet Rows for all saved results.
  3. In Game Records, select the first empty cell in column A, beginning with A5. Selecting the row number can also work, but selecting the column-A cell is the recommended method.
  4. Keep the cell selected rather than placing a text cursor inside it, then paste.
  5. Paste into column A only. StepCat fills input columns A–M.
  6. Do not paste over formula columns N–Z.
Estimate rows leave Final Earned blank. Workbook formula column O calculates Estimated Earned. Notes copy into existing column M. The Summary shows completed Free Game count and recorded chips separately from paid-game counts and cash totals.
Calculation baseline: v246.2 was the last substantive workbook release that established the correct core calculations. The v246.3 workbook used the same formulas and was also calculation-correct; v246.3 was primarily a webpage/interface release.
Migration requirement: users may continue using v246.2 or v246.3 for those established calculations. Migration is required to adopt v246.3.5 improvements. Copy only populated Game Records cells A5:M into A5 of v246.3.5—preferably as values only. Do not copy an entire sheet, headers, or columns N–Z. Keep the older workbook as a backup until records and totals are verified.

7. Workbook-only records

Annual membership or subscription fees are non-game costs. Enter them directly in Game Records with Payment / Record Type set to Subscription — membership charge only, place the cost in Entry Fee, and use N/A only for game-specific fields that do not apply. Use Free Game — completed challenge/chips only for a completed free-entry challenge or chips/game-credit record.

8. Install StepCat

Open the hosted web version in a supported browser and use the compact Install StepCat strip near the top of the calculator. Tap Install when the browser offers native app installation. Tap Not now to hide the strip for the current browser session; it returns during a later session.

When the native prompt is unavailable, the button reads How to Install and opens the installation area in Help → Guides & Downloads. Add to Home Screen remains there as the shortcut-style alternative. The strip is hidden while StepCat is running in installed-app mode.

9. Use in-app Help

The Help panel is a compact one-at-a-time accordion. Calculate and Save opens first; expand only the topic you need. Full workbook maps and report descriptions remain in Full Documentation.
