StepCat Quick Start Guide

Quick Start • Illustrated Guide

StepCat Calculator and Workbook v252

Follow the current workflow, save a projected or finalized result, and transfer the matching A–M row into the StepCat workbook.

1. Choose Entry Mode first

Tap Estimate for a projection or Finalized for a completed result. Then confirm Member or Non-Member. These are the first required choices.

2. Enter the required calculation fields

Game Entry shows required calculation fields first. Estimate requires Gross Pot, Entry Fee, and Eligible Players. Total Players adds context. Finalized also requires Final Earned unless the record is disqualified.

Tap any i information button for field help. Blocking validation still appears beside the affected field, under Calculate & Save, and in one brief toast.

3. Open Additional Details only when needed

Game Name, dates, Date Format, and Payment / Record Type stay inside the optional Additional Details drawer. Open it only when those details are useful for Saved History or the workbook. Notes remains available for details such as a Hybrid cash-and-points breakdown.

4. Complete a Finalized result

In Finalized mode, the disqualification control appears immediately before Final Earned / Chips. Its neutral state reads Not Disqualified. When selected, it turns into a warning state, sets Final Earned to 0.00, and locks the field until switched off.

5. Calculate, save, or begin a new entry

Calculate & Save validates the entry and stores one result. A successful save clears the completed draft so it cannot return as an unfinished duplicate. Start New Entry and Clear Entry ask before discarding meaningful unsaved information. Clear Entry also provides Restore Cleared Fields.

6. Review or finalize the Saved History card

Estimate cards show projected earnings while Accounting Result and ROI remain N/A. Each record receives a permanent non-editable SC-#### Record ID. Tap Finalize This Estimate when the game ends; StepCat updates that same record and keeps its ID and history position.

7. Copy the result into the workbook

Tap Copy This Sheet Row, open Game Records, select the first empty cell in column A, and paste. Copy All Sheet Rows transfers all saved A–M records without a header row because row 4 already contains workbook headers.

Paste in A–M only. Never overwrite formula columns N–Z.

8. Use the StepCat-themed workbook

The workbook uses the app palette while preserving spreadsheet cues: pale gold/cream for user input, blue-gray for protected formulas, green for Profit, gray for Draw, blue for Estimate, yellow for Free Game, and red for losses or warnings.

9. Enter A–M and leave N–Z intact

Rows 5-504 are formula-ready. Row 505 is the archive boundary. Record Review identifies missing information, formula problems, and invalid Free Game rows with a non-zero Entry Fee. Valid Free Games use a $0 Entry Fee.

10. Read the reports

Summary gives exact Profit, Draw, and Disqualified counts, excludes subscriptions from Games by Result, and tracks membership fees separately. Game Comparisons separates completed paid games from Estimates, Free Games, and subscriptions. Best Results uses readable blank-state messages.

11. Customize Settings and open Help

All ordinary Settings changes save automatically. Remembered choices control Entry Mode, Membership Type, Payment / Record Type, and unfinished inputs. Default-open settings apply when StepCat starts or refreshes without overriding a drawer the user manually opened or collapsed during the current session. Restore Defaults returns Haptic Feedback to Low.

12. Install StepCat or send feedback

The main Install StepCat card reports whether installation is available. Its information button explains Add to Home Screen and shortcut alternatives. Installation must be tested from the hosted page. Feedback prepares a message for the user’s email app.
