Install StepCat

StepCat can be installed from the in-app Install StepCat button, from a browser install prompt, or from a browser Add to Home Screen option.

The exact install screen and home-screen icon appearance can vary by device, browser, operating system, and launcher. Some installs may show a small browser badge or slightly different icon style. StepCat works either way.
  1. Open StepCat in your browser.
  2. Tap Install StepCat in the StepCat install banner, or open Help, Guides & Feedback and tap Install StepCat later.
  3. Follow the confirmation screen shown by your browser.

Quick Start

  1. Choose Estimate or Finalized.
  2. For Estimate, choose Member or Non-Member, then enter Gross Pot, Entry Fee, and Eligible Winners.
  3. For Finalized, confirm Game Type, then enter Entry Fee and the Official Earned Amount. Turn on Disqualified / Lost Entry Fee only when the full fee was forfeited.
  4. Add optional details when useful.
  5. Tap Calculate & Save.
  6. For routine spreadsheet entry, use Copy Latest Row and paste into the next empty row.

Which Row Should I Paste?

  • The visible Result Card is the newest saved calculation. Copy Latest Row copies that completed spreadsheet row.
  • The corresponding card in Saved History contains the same completed values in the same column order. Use its Copy Row button when you need that particular saved game.
  • For normal ongoing use, copy only the newest result and paste it into the next empty spreadsheet row.
  • Use Copy All Saved Rows for an initial import, batch transfer, backup, or rebuild. Pasting the same full history into a sheet that already contains those games creates duplicates.
  • Use the copy buttons rather than manually copying the visible text from the Result Card.
Key point: The Result Card and the matching Saved History card are two views of the same saved calculation. Saved History is not a separate calculation.

Two Safe Spreadsheet Workflows

Choose how Saved History should work for you.

Complete-history workflow
Keep every entry in StepCat as a local archive. After the first full-history transfer, add future games with Copy Latest Row or the individual Copy Row button. Do not repeatedly paste Copy All Saved Rows into a spreadsheet that already contains those entries.
Transfer-queue workflow
  1. Tap Copy All Saved Rows and paste the rows into the spreadsheet.
  2. Confirm that every row pasted into the correct columns and that no entry is missing.
  3. Only after verification, delete each transferred entry individually from Saved History.
  4. Leave untransferred entries in Saved History. The next full-history copy will contain only the remaining entries.
Important: Deleting an entry removes StepCat's local Saved History copy. It does not remove a row that was already pasted into the spreadsheet. Keep the entry in StepCat, or make another backup, when StepCat should remain your complete archive.

Optional Profitability Analysis Template

This blank template is optional and contains no personal game records.

  1. In Spreadsheet Copy Setup, include Game Type, Gross Pot, Adjusted Pot, Eligible Winners, and Total Players.
  2. Leave the header-row toggle off because the template already has headers.
  3. Paste the first copied StepCat row into Game Records starting in cell A5, then use the next empty row for each new game.
  4. Use Count Source, Confidence, and Notes only when useful.
Calculated before copying: For Estimate rows, StepCat calculates Adjusted Pot, estimated Earned, Profit or Draw, ROI, and Result. For Finalized rows, the Official Earned Amount controls Earned, Profit, Draw/Lost, ROI, and Result. The template stores these StepCat values and does not recalculate Adjusted Pot.
Calculated by the template: Challenge Length, Net Profit, Eliminated Players, and Elimination Rate. Summary and comparison areas update from the completed rows. The template does not calculate weekly payouts.
Template download: Use Download Blank Profitability Template in the Helpful Links box at the top of this guide.
  • Count Source: Reported, Estimated, or Partly Estimated.
  • Confidence: High, Medium, or Low for estimated counts.
  • Notes: Optional explanation of an estimate or unusual result.

Feedback and Disclaimer

Sending Feedback

StepCat prepares an email in your device's default email app. It does not send feedback automatically.

  1. Open Help, Guides & Feedback and tap Write Feedback.
  2. Enter your message and tap Send Feedback.
  3. If prompted, choose an email app. Review the prepared email and tap Send.
Privacy note: Feedback is sent by email. StepCat does not send the message automatically or store it inside the app.

Storage and Safety

  • Saved History, inputs, and preferences are stored locally in the current browser.
  • Copy important saved rows before clearing browser or site data.
  • Verify spreadsheet transfers before deleting individual Saved History entries.
  • End Date cannot be before Start Date.
  • Restoring default settings does not erase Saved History.
