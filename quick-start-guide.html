StepCat Quick Start Guide

Quick Start • Illustrated Guide

StepCat Calculator v250.1

Enter a projected or finalized result, save it, and copy the matching A–M row into the Profitability Analysis workbook.

1. Enter the record information

Add the game name, dates, date format, and Payment / Record Type. Optional fields may remain blank when they do not apply.

2. Confirm membership and enter calculation details

Tap Member or Non-Member to confirm the current entry. Non-Member uses 85% of Gross Pot; Member uses 100%.

3. Complete a finalized result

Finalized mode uses the official total returned. Enter the full Final Earned amount, not only the extra profit.

4. Add notes, then calculate and save

Use Notes for details such as a Hybrid cash-and-points breakdown. Calculate & Save validates the entry and stores one Saved History result.

5. Review Saved History

The newest saved result opens automatically. Review the outcome, official amount, profit or draw, ROI, record details, and reference estimate.

6. Copy the row into the workbook

  1. Tap Copy This Sheet Row.
  2. Open your native StepCat Google Sheet and go to Game Records.
  3. For a new record, select the next prepared blank cell in column A, beginning with A5.
  4. For a forgotten game, select a cell inside the table near the correct location and choose Insert row above or Insert row below.
  5. Paste into column A only so the copied row fills A–M. Do not paste over formula columns N–Z.
Native Google Sheets behavior: Rows inserted from inside the Game Records table automatically receive formulas, dropdowns, formatting, and visible cell borders. Record Review flags Formula columns missing if a populated row ever loses an N–Z formula.

7. Make your own Google Sheets copy

  1. If Google asks which account to use, select the account where you want your StepCat copy stored. The account list comes from accounts already signed in on your device; other users see only their own accounts.
  2. Tap Make a StepCat Google Sheets Copy.
  3. In Google Sheets, choose Make a copy. You may keep the suggested title or rename it.
  4. The copy saves to My Drive by default. To choose another folder, tap the arrow beside Folder, select any folder in your Google Drive, and tap Select.
  5. Tap OK to create the editable native Google Sheets workbook.
Do not use Save As. No file format is required. Save As exports the workbook to Excel, PDF, ODS, CSV, TSV, or a web page instead of creating the native Google Sheets copy used by StepCat.
Mobile options: The link may open the Make a copy prompt directly. If the template opens in the Google Sheets app instead, use the three-dot menu and choose Make a copy. The Google Sheets app is recommended for convenient mobile editing; browser use may also work but is less convenient. The Google Drive app is optional.

8. Follow the workbook instructions

The Instructions sheet explains where to enter records and which columns calculate automatically. Game Records rows 1–4 remain compact and frozen.

Migrating older records: Compare the older workbook’s A–M headers with v250.1 first. When the order matches, paste only populated A–M values into A5 of a new unused v250.1 copy, or into the next available A–M row when that copy already contains records. Never copy whole sheets, headers, Record Review, or N–Z.

9. Enter values in A–M and leave N–Z intact

The frozen headings remain visible while scrolling. Enter or paste only in the yellow A–M area; the N–Z formula columns calculate automatically.

10. Use Record Review to check the workbook

Record Review lists each non-subscription game, identifies the calculated result, flags fields that may deserve attention, mirrors Notes, and summarizes results.

Final workbook check: paste into the next blank column-A cell, keep N–Z unchanged, enter subscriptions only as workbook-only non-game costs, and archive the workbook when the record area reaches row 505.

11. Send feedback from Help

Open Help (?), scroll to Guides & Downloads, and tap Write Feedback. The feedback form opens over the Help drawer, so Cancel returns to the same location.

  1. Enter a question, issue, or suggestion.
  2. Tap Send Feedback.
  3. Your email app opens with the recipient, subject, and message prepared.
  4. Review and send the email, then swipe back to return to StepCat. Help remains open at the same location when the browser preserves the page.
Privacy note: The addresses shown in the guide image are generic examples. StepCat does not place an email address in the workbook. The actual feedback recipient appears only when the device prepares the email.
