StepCat Quick Start Guide

Quick Start • Illustrated Guide

StepCat Calculator v253.0 and Workbook v253.0

As of August 4, 2026, v253.0 is the recommended workbook.

Use StepCat as a guided calculator, or maintain the Google Sheet directly from any signed-in device. Completed records in the Sheet are cross-device; StepCat local fields and Saved History are not.

1. Choose Entry Mode and Membership Type

Tap Estimate for a projection or Finalized for a completed result. Membership Type stays dimmed until Step 1 is confirmed, then receives a gold edge to show that Step 2 is the current action. Confirm Member or Non-Member; the selected choice remains bright gold while the completed section changes to green. Game Entry then receives the gold current-step edge, and the first required field needing attention receives the same gold cue. When all required fields are ready, Calculate Result becomes the gold current action.

2. Complete Game Entry

Step 3 keeps the familiar labeled inputs while reducing phone scrolling. Type only the values shown on the game platform; no field names, tab characters, or specially formatted text are required.

  • Game Details: Game Name, Start Date, End Date, Payment / Record Type, Notes, and Copied Date Format.
  • Calculation Information: Gross Pot, Entry Fee, Eligible Players, and Total Players.
  • Final Result: Final Earned / Chips and Disqualified status for Finalized entries. Estimates require no final amount.

These are subsections of Step 3, not additional numbered workflow steps. A subsection stays open while you work. StepCat does not automatically scroll or open the keyboard as you make Step 1 and Step 2 choices. Choose Continue when you are ready to collapse the current subsection and open the next one. Normal progression changes the visible section in place without automatically scrolling or opening the keyboard. Use the Guided Sections | Show All Fields switch whenever you want every Step 3 field visible together. Continue buttons appear only in Guided Sections; Show All Fields uses scrolling and Review Entry as the next action.

Finalized entries: complete Final Result

In Finalized mode, the disqualification control appears immediately before Final Earned / Chips. It uses three explicit states: dim gray when unavailable, muted amber when available but off, and red when Disqualified is selected. Turning it on sets Final Earned to 0.00 and locks the field until switched off.

3. Review, Calculate & Save

When the required Step 3 values are ready, choose Review Entry. Step 4 presents Entry Mode, Membership Type, Game Details, Calculation Information, Final Result together, including Notes and Copied Date Format before anything is saved. Opening the review does not automatically focus a field or open the mobile keyboard.

Choose Edit beside any review group to return to the exact Step 3 subsection. Choose Continue Editing to close the review without saving and return to Game Entry.

Calculate & Save appears inside the review so a Saved History record is not created until the user has inspected the completed entry.

Calculate, save, or begin a new entry

After reviewing Step 4, choose Calculate & Save to validate the entry and store one result. A successful save keeps the completed fields visible for review during the current session while removing them from unfinished-draft recovery. Use View Saved Result to open the newest history card, Undo Last Save to remove that newest record, or Start New Entry when you are ready to reset the form.

Use Clear Game Entry at the bottom of Step 3 when needed. Restore Cleared Fields appears in the same location after clearing.

Device storage: StepCat Saved History, settings, and unfinished fields remain in the current browser/device and do not transfer automatically.

4. Review or finalize Saved History

Estimate cards show projected earnings while Accounting Result and ROI remain N/A. Each record receives a permanent non-editable SC-#### Record ID. History cards use green for Profit, amber for Draw, red for Loss or Disqualification, blue for Estimate, and teal for Free Game results. The Result Color Guide beside Saved History writes out the same key, and every card also names its result. Tap Finalize This Estimate when the game ends; StepCat updates that same record and keeps its ID and history position.

5. Copy records into the workbook

The calculator is optional. The Google Sheet can be maintained directly on a phone, tablet, or computer. Enter or paste A–M, leave N–Z untouched, and the workbook calculates its own results and reports.

Switching devices: open the same Google Sheet through the same Google account. Only records already entered in the Sheet are available on the other device; an unfinished StepCat form and local Saved History are not transferred.

Tap Copy This Sheet Row, open Game Records, select the first empty cell in column A, and paste. Copy All Sheet Rows transfers all saved A–M records without a header row because row 4 already contains workbook headers.

Paste in A–M only. Never overwrite formula columns N–Z.

6. Use the workbook directly or with StepCat

Use one Google Sheets copy: create it from Help & Resources, then open that same Sheet from any device signed into the same Google account. v253.0 is self-contained and can be used with or without StepCat.

The workbook uses the app palette while preserving spreadsheet cues: pale gold/cream for user input, blue-gray for protected formulas, green for Profit, gray for Draw, blue for Estimate, yellow for Free Game, and red for losses or warnings.

7. Understand workbook columns A–Z

Enter or paste records in A–M. Protected expanding formulas calculate N–Z automatically. To add a forgotten game later, insert one whole Game Records row above or below the correct record and complete A–M. This direct-entry workflow is the workbook's normal independent operating mode; StepCat simply prepares the same A–M inputs for you.

8. Read reports and totals

Summary gives exact Profit, Draw, and Disqualified counts, excludes subscriptions from Games by Result, and tracks membership fees separately. Game Comparisons separates completed paid games from Estimates, Free Games, and subscriptions. Best Results uses readable blank-state messages.

9. Customize Settings and Help

Each Quick Explanation header includes a short helper line, followed by Expand All and Collapse All controls. Settings changes save automatically. Restore Defaults replaces saved preferences with StepCat’s original settings, including Haptic Feedback set to Low. It does not delete Saved History, current entry information, or spreadsheet records. Section Display, Starting State, Entry Preferences, Help & Guides, Haptic Feedback, and Help & Feedback are grouped separately. Every setting that needs explanation includes an information button. Informational popups use one large Close button. Default-open settings apply when StepCat starts or refreshes without overriding a drawer the user manually opened or collapsed during the current session. Help also explains that StepCat data is device-local and that the Google Sheet is the cross-device record.

10. Install StepCat or send feedback

Write Feedback is available in the main-page footer, Settings, and Help. The compact Install StepCat prompt reports whether installation is available. Its mahogany-brown information button opens a compact dialog explaining Add to Home Screen and shortcut alternatives. Use the large Close button to return to the same place on the main page. Installation must be tested from the hosted page. Feedback prepares a message for the user’s email app.

11. Move records from an earlier spreadsheet

Copy populated A5:M cells from the older Game Records sheet and paste them into A5 of v253.0. Existing records do not need to be retyped.

Computer: use Paste special → Values only. Phone or tablet: regular Paste is acceptable when only A–M are copied. Minor appearance differences can be corrected later.

Do not copy N–Z, headers, entire rows, entire sheets, reports, or charts.

Release Note

As of August 4, 2026, v253.0 is the recommended workbook. It corrects missing N–Z calculations when a whole Game Records row is inserted later, such as when adding a forgotten game.

Users of earlier versions should create a new v253.0 Google Sheets copy and transfer populated A5:M values only.

Cross-device note: the workbook may be maintained directly through Google Sheets. StepCat itself does not synchronize Saved History or unfinished fields between devices.
