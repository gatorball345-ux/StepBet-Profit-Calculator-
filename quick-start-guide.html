StepCat Quick Start Guide

Quick Start • Illustrated Guide

StepCat Calculator v253.0 and Workbook v253.0

As of August 4, 2026, v253.0 is the recommended workbook.

Use StepCat as a guided calculator, or maintain the Google Sheet directly from any signed-in device. Completed records in the Sheet are cross-device; StepCat local fields and Saved History are not.

1. Choose Entry Mode (Step 1) and Membership Type (Step 2)

Tap Estimate for a projection or Finalized for a completed result. Membership Type stays dimmed until Step 1 is confirmed, then receives a gold edge to show that Step 2 is the current action. Confirm Member or Non-Member; the selected choice remains bright gold while the completed section changes to green. Game Entry then receives the gold current-step edge, and the first required field needing attention receives the same gold cue. When all required fields are ready, Calculate Result becomes the gold current action.

2. Complete Game Entry (Step 3)

Game Entry shows required calculation fields first. Requirement badges appear beneath field names so the separate i buttons remain clearly tappable. After Entry Mode is selected, each mode-dependent badge simplifies to Required or Optional. Required fields must be completed for that mode; Optional fields may be left blank and can still be entered for record or comparison details. Date Format is a web setting, not an entry requirement.

Tap any i information button for field help. Blocking validation still appears beside the affected field, under Calculate & Save, and in one brief toast.

3. Show Optional Fields only when needed

Game Name, dates, Date Format, and Payment / Record Type stay inside the optional Optional Fields drawer. When closed, the helper describes which extra details are available. When opened, the control changes to Hide Optional Fields and the helper changes to Collapse the optional information shown below. Notes remains available for details such as a Hybrid cash-and-points breakdown.

4. Complete a Finalized result

In Finalized mode, the disqualification control appears immediately before Final Earned / Chips. It uses three explicit states: dim gray when unavailable, muted amber when available but off, and red when Disqualified is selected. Turning it on sets Final Earned to 0.00 and locks the field until switched off.

5. Calculate Result (Step 4), save, or begin a new entry

Calculate & Save validates the entry and stores one result. A successful save clears the completed draft so it cannot return as an unfinished duplicate. Start New Entry remains visible as the secondary workflow action. Clear Entry and Restore Cleared Fields are grouped under Entry Tools to reduce crowding.

Device storage: StepCat Saved History, settings, and unfinished fields remain in the current browser/device and do not transfer automatically.

6. Review or finalize the Saved History card

Estimate cards show projected earnings while Accounting Result and ROI remain N/A. Each record receives a permanent non-editable SC-#### Record ID. Tap Finalize This Estimate when the game ends; StepCat updates that same record and keeps its ID and history position.

7. Copy the result into the workbook

The calculator is optional. The Google Sheet can be maintained directly on a phone, tablet, or computer. Enter or paste A–M, leave N–Z untouched, and the workbook calculates its own results and reports.

Switching devices: open the same Google Sheet through the same Google account. Only records already entered in the Sheet are available on the other device; an unfinished StepCat form and local Saved History are not transferred.

Tap Copy This Sheet Row, open Game Records, select the first empty cell in column A, and paste. Copy All Sheet Rows transfers all saved A–M records without a header row because row 4 already contains workbook headers.

Paste in A–M only. Never overwrite formula columns N–Z.

8. Use the StepCat-themed workbook

Use one Google Sheets copy: create it from Help & Resources, then open that same Sheet from any device signed into the same Google account. v253.0 is self-contained and can be used with or without StepCat.

The workbook uses the app palette while preserving spreadsheet cues: pale gold/cream for user input, blue-gray for protected formulas, green for Profit, gray for Draw, blue for Estimate, yellow for Free Game, and red for losses or warnings.

9. Enter A–M and leave N–Z intact

Enter or paste records in A–M. Protected expanding formulas calculate N–Z automatically. To add a forgotten game later, insert one whole Game Records row above or below the correct record and complete A–M. This direct-entry workflow is the workbook's normal independent operating mode; StepCat simply prepares the same A–M inputs for you.

10. Read the reports

Summary gives exact Profit, Draw, and Disqualified counts, excludes subscriptions from Games by Result, and tracks membership fees separately. Game Comparisons separates completed paid games from Estimates, Free Games, and subscriptions. Best Results uses readable blank-state messages.

11. Customize Settings and open Help

Each Quick Explanation header includes a short helper line describing what opens beneath it. All ordinary Settings changes save automatically. Remembered choices control Entry Mode, Membership Type, Payment / Record Type, and unfinished inputs. Default-open settings apply when StepCat starts or refreshes without overriding a drawer the user manually opened or collapsed during the current session. Restore Defaults returns Haptic Feedback to Low. Help also explains that StepCat data is device-local and that the Google Sheet is the cross-device record.

12. Install StepCat or send feedback

The main Write Feedback button centers its title and helper text at every phone width. The main Install StepCat card reports whether installation is available. Its information button opens a compact dialog explaining Add to Home Screen and shortcut alternatives. Close it with X or Close to return to the same place on the main page. Installation must be tested from the hosted page. Feedback prepares a message for the user’s email app.

Release note

As of August 4, 2026, v253.0 is the recommended workbook. It corrects missing N–Z calculations when a whole Game Records row is inserted later, such as when adding a forgotten game.

Users of earlier versions should create a new v253.0 Google Sheets copy and transfer populated A5:M values only.

Cross-device note: the workbook may be maintained directly through Google Sheets. StepCat itself does not synchronize Saved History or unfinished fields between devices.

13. Move records from an earlier spreadsheet

Copy populated A5:M cells from the older Game Records sheet and paste them into A5 of v253.0. Existing records do not need to be retyped.

Computer: use Paste special → Values only. Phone or tablet: regular Paste is acceptable when only A–M are copied. Minor appearance differences can be corrected later.

Do not copy N–Z, headers, entire rows, entire sheets, reports, or charts.
